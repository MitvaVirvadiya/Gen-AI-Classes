# Capstone — one agent you keep

## One-sentence truth

The course is finished when you have a documented agent that uses
*your* notes and *your* tools, not when you have starred 40 repos.

## What you will build (later)

A study agent over this repo:

1. RAG over `**/notes.md` (Track 4, vanilla, then optional LlamaIndex)
2. Tools: search index, read a lesson, tick `PROGRESS.md`
3. Loop with a step limit (Track 5.1)
4. Optional: expose the tools via MCP (5.5)
5. Eval set: 15 questions like "what is RoPE?" and "how do I train BPE?"

## Definition of done

- a README in the capstone folder that tells *future you* how to run it
- eval scores written down
- no framework you cannot delete

We do not start this until Tracks 1–4 are ticked. It is the exam.
