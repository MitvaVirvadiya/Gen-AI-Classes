# Track 3 — Hugging Face and open models

Hugging Face is not a model. It is the standard library: a Hub of
weights, a `transformers` package that loads them, tokenizers, datasets,
and trainers (`peft`, `trl`).

We come here *after* Track 1 so `AutoModelForCausalLM` is not magic.
